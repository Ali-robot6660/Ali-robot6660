### 🔬 Current Research

**Prognostics and Health Management (PHM) for smart fishing vessels**

- Real-time anomaly detection on multi-sensor data from ship equipment (net hauler, hydraulic pump): pressure, temperature, vibration
- Reconstruction-based models trained on normal data only: LSTM-AE, Transformer-AE, VAE
- Fair model comparison: multiple seeds, threshold from clean validation data, equal false-alarm rate
- Early-Exit models for lightweight inference on on-board edge PCs, aware of operating modes (mooring, sailing, hauling)
